# Entornos de desarrollo · Tarea extraordinaria

Ejercicios de la tarea extraordinaria de **Entornos de Desarrollo** (1º DAW), escritos en **Java** como proyecto **Maven**, con una clase de **pruebas unitarias con JUnit 5**.

## Contenido

El proyecto está en [`TareaExtraordinariaEntornos/`](TareaExtraordinariaEntornos):

- **`GestionExamenFinal`** y su test `GestionExamenFinalTest`: clase que clasifica el resultado de un alumno según la nota, y pruebas que comprueban sus casos.
- **Casos de modelado con varias clases**: excursión (`ExamenExcursion/`), parking (`ExamenParking/`), piscina (`ExamenPiscina/`) y un caso ampliado (`ExamenJunio/`).

## Cómo abrirlo

Requiere un JDK. Abre la carpeta `TareaExtraordinariaEntornos` como proyecto Maven en IntelliJ IDEA. Los tests están en `src/test/java`.
